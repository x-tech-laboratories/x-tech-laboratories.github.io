# Instructions for AI agents

This repository is the X-Tech Laboratories website, built with Astro Starlight as a static site.

- Page content lives in `src/content/docs/` as MDX; the frontmatter `title` is the page heading, so do not add an H1.
- The sidebar is set in `astro.config.mjs`; guideline pages are ordered by `sidebar.order` in their frontmatter.
- `org/` is a submodule of the organisation's `.github` repository; change logos and icons there, never in `org/`, and do not copy them into this repository.
- Prefer Markdown and Starlight's built-in components; do not add dependencies without a clear need.
- Keep the wording plain and the claims honest; do not invent statistics, members or partners.
- Awesome AI-Assisted Open Source entries live in `src/data/awesome.json`; each needs a link to the maintainers' own evidence of AI use.
- `src/data/readiness.json` is generated by `npm run readiness`; never edit it by hand.
- Keep any code simple and readable enough for a person to maintain without AI.
- Run `npm test` and `npm run build` and make sure both succeed before proposing a change.
- In the pull request, state which parts were written or changed by AI.

## X-Tech standards

- Follow the [Application Standard](https://x-tech-laboratories.github.io/standards/application/) and the
  [Design Guidelines](https://x-tech-laboratories.github.io/standards/design/), whose source is `src/content/docs/standards/`
  in [x-tech-laboratories.github.io](https://github.com/x-tech-laboratories/x-tech-laboratories.github.io). Ask before
  changing either, since a change applies to every X-app.
- Use [X-Libs](https://github.com/x-tech-laboratories/X-Libs) and Halon ([X-Themes](https://github.com/x-tech-laboratories/X-Themes))
  before writing your own code: check the module table in the X-Libs README first.
- A feature another app could use belongs in X-Libs, or Halon for styling, with tests and a README row. If that is out
  of reach, add it to the candidates in X-Libs' `docs/TODO.md`.
