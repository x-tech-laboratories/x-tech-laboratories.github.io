title: Get involved
---

X-Tech Laboratories is built first for its founder's own daily use, and it keeps going whether or not
anyone joins. It is also built in the open, so anyone can use the apps, and it gets better with every
person who does.

## Use the apps

Every app is free software under the GPL, and the [projects page](/projects/) says how ready each one
is. If an app is missing something you need, open an issue on its repository. If it is something only
some people want, it may fit best as a setting or a plugin, and every X-app takes plugins the same way.

## Bring a project

Maintain a project that does the same job as one of ours, or that could combine with one? Talk to us
about bringing their best features together. See [consolidation](/guidelines/consolidation/) for how
we go about it.

Built something with AI that you'd like others to use and improve? Before it becomes another
one-person project, consider bringing it into X-Tech Laboratories.

Maintain an open source project that welcomes AI-assisted contributions? Suggest it for
[Awesome AI-Assisted Open Source](/awesome). And before starting something new, check whether an existing project could take your
idea as a plugin or a setting instead.

## Join the discussion

Plugin interfaces, CI recipes, disclosure formats and agent guidelines are open questions, and we want many
voices on them.

- [GitHub Discussions](https://github.com/orgs/x-tech-laboratories/discussions): ideas, questions and longer
  conversations that should stay findable.
- [#x-tech-laboratories:matrix.org](https://matrix.to/#/#x-tech-laboratories:matrix.org): the main X-Tech Laboratories channel on Matrix.
- [#x-tech-laboratories-general:matrix.org](https://matrix.to/#/#x-tech-laboratories-general:matrix.org): general chat.

For concrete proposals, open an issue on [GitHub](https://github.com/x-tech-laboratories/x-tech-laboratories.github.io/issues).

## Build the tooling

Templates, review bots, CI recipes and documentation all need hands, human and otherwise. Browse
the repositories at [github.com/x-tech-laboratories](https://github.com/x-tech-laboratories).
