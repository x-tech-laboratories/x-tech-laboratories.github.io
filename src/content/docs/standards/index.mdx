These pages set how X-Tech Laboratories' own apps are built and branded. Unlike the
[guidelines](/guidelines), which any project can adopt one at a time, the standards apply to every
X-Tech app together, so the shared code in X-Libs and the shared styling in Halon serve all of them.

- [Application Standard](/standards/application): the stack, shared code, repository layout and conventions every X-Tech app follows.
- [Design Guidelines](/standards/design): fonts, colour scheme and naming scheme.

A change to a standard goes through a pull request on
[GitHub](https://github.com/x-tech-laboratories/x-tech-laboratories.github.io), like any other page.
